## Data Files

### cv-data.js
Contains the main CV information organized by profile:
- Personal information (shared across all profiles)
- Professional summary (profile-specific for each role)
- Work experience (shared across all profiles)
- Selected projects (shared across all profiles)
- Education (shared across all profiles)
- Certifications (shared across all profiles)
- Languages (shared across all profiles)
- Profile-specific content for title and summary

### skills.js
Organized technical skills by profile:
- **delivery-manager**: Skills focused on delivery management, stakeholder coordination, and Agile methodologies
- **frontend-lead**: Skills focused on frontend development, technical leadership, and web technologies
- **technical-project-manager**: Skills focused on project management, technical coordination, and IT project delivery
- **default**: Common skills across all profiles

### versions.js
Configuration file for CV version generation:
- Defines the three profile versions (delivery-manager, frontend-lead, technical-project-manager)
- Specifies output directories and metadata for each version
- Controls which versions are generated by the build process

### keywords.js
SEO and search optimization keywords:
- Job titles
- Technical keywords
- Accessibility keywords
- Project management keywords
- Soft skills
- Industry keywords

## Build Process

### Building the project
When you make changes to the data files, you need to run the build script to generate all CV versions:

```bash
npm run build
```

The build process:
1. Reads configuration from `data/versions.js` to determine which profiles to generate
2. Reads CV data from `data/cv-data.js` (shared and profile-specific content)
3. Reads skills data from `data/skills.js` (profile-specific skills)
4. For each profile:
   - Combines shared data with profile-specific content (title, summary, skills)
   - Generates a personalized cvData object for that profile
   - Creates the directory structure: `dist/versions/<profile>/en/` and `dist/versions/<profile>/es/`
   - Copies and customizes HTML, CSS, and JavaScript files for each language
5. Updates the development version in `src/app.js` with default profile data

### Build Commands
- `npm run build` - Generate all CV versions for all profiles and languages
- `npm run dev` - Build and open development version from src/
- `npm run preview` - Build and open production version from dist/

## Usage

To view the CV versions (development):
1. Run `npm run build` to generate all profile versions
2. Open `src/index.html` in a web browser for the default development version
3. The content will be dynamically loaded from the data files

To view specific CV versions (production):
1. Run `npm run build` to generate all profile versions
2. Navigate to the desired profile and language:
   - Delivery Manager (English): `dist/versions/delivery-manager/en/index.html`
   - Delivery Manager (Spanish): `dist/versions/delivery-manager/es/index.html`
   - Frontend Lead (English): `dist/versions/frontend-lead/en/index.html`
   - Frontend Lead (Spanish): `dist/versions/frontend-lead/es/index.html`
   - Technical Project Manager (English): `dist/versions/technical-project-manager/en/index.html`
   - Technical Project Manager (Spanish): `dist/versions/technical-project-manager/es/index.html`

To print the CV:
1. Open any version of the CV in a web browser
2. Use the browser's print function (Ctrl+P or Cmd+P)
3. The print.css file will optimize the layout for printing
